# SMAClite Slight Ally Advantage Dataset

This archive contains 500 individual SMAClite map configurations in `maps/`.

- 2-20 total units per map.
- 1-3 spawn groups per faction.
- One race per faction.
- 5-15% calculated allied army-strength advantage.
- All nine supplied standard units and all eight terrain presets included.

See `manifest.json`, `dataset_summary.json`, and `validation_report.json` for details.
