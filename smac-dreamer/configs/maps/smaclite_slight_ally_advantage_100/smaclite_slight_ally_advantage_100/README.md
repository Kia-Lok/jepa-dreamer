# SMAClite Slight Ally Advantage — 100 Map Dataset

Balanced 100-map subset of the validated 500-map dataset.

- 100 individual SMAClite JSON maps
- 2–20 total units per map
- 5–15% calculated allied strength advantage
- One race per faction
- All nine standard unit types and all eight terrain presets
- Spawn groups: 40 one-group, 40 two-group, 20 three-group maps
- All nine ordered race matchups represented
- Advantage modes balanced 34/33/33
